# Portfolio Builder

Generate compelling case studies and portfolio showcases for completed Oskris web design projects.

## Case Study Structure

### 1. Hero Section
- Project name and client industry
- One-line impact statement ("Increased online orders by 200%")
- Hero screenshot of the website

### 2. The Challenge
- 2-3 sentences about client's problem
- Why they needed a new website
- Specific pain points (outdated design, no mobile support, slow, etc.)

### 3. Our Solution
- Design approach taken
- Key features implemented
- Technology used
- Special considerations (multilingual, e-commerce, etc.)

### 4. The Process (Optional — for detailed case studies)
- Discovery phase highlights
- Design evolution (wireframe → mockup → final)
- Development challenges solved
- Timeline from start to launch

### 5. Results
- Specific metrics (load time improvement, traffic increase, conversion rate)
- Client testimonial quote
- Before/after screenshots (side by side)

### 6. Tech Stack
- Technologies used (badges/icons)
- Features list with icons

## Output Formats
- **HTML page** — For showcasing on websitedesign.oskris.com
- **PDF** — For attaching to proposals
- **Social media** — Condensed version for Facebook/Instagram carousel

### Full Case Study (Website)
Generate complete HTML with:
- Responsive layout
- Image placeholders (user provides screenshots)
- Clean typography
- CTA at bottom ("Want similar results? Let's talk")
- Consistent with Oskris branding

## Best Practices
- Lead with RESULTS, not process
- Use specific numbers ("40% faster" not "much faster")
- Include real client quotes
- Show before/after visually
- Keep it scannable (bullets, short paragraphs)
- End with a clear CTA
- Tag the industry for searchability
