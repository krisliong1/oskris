# 5-Agent Website Design Workflow

## 工作流架构

### Agent 1: Discovery (发现)
**职责**: 客户研究、需求分析、市场调研
```
输出:
- [ ] 客户问卷调查结果
- [ ] 业务目标文档
- [ ] 竞品分析报告
- [ ] 项目范围文档 (SOW)
```

### Agent 2: Designer (设计师)
**职责**: 视觉设计、UI/UX、品牌规范
```
输出:
- [ ] 线框图 (Wireframes)
- [ ] 视觉设计稿 (Mockups)
- [ ] 品牌指南 (Style Guide)
- [ ] 交互原型 (Prototypes)
```

### Agent 3: Creator (开发者)
**职责**: 代码实现、功能开发、集成
```
输出:
- [ ] HTML/CSS/JS代码
- [ ] 响应式实现
- [ ] 动画效果
- [ ] 第三方集成
```

### Agent 4: Reviewer (审核员)
**职责**: 质量检查、性能测试、SEO审核
```
输出:
- [ ] PageSpeed报告 (>90分)
- [ ] 移动友好测试
- [ ] 浏览器兼容性
- [ ] SEO技术审核
```

### Agent 5: Launcher (发射员)
**职责**: 部署、DNS配置、上线监控
```
输出:
- [ ] GitHub Pages部署
- [ ] 域名DNS配置
- [ ] SSL证书安装
- [ ] 上线监控设置
```

## 协调机制

### 阶段交接
- **Discovery → Designer**: 需求文档完成
- **Designer → Creator**: 设计稿确认
- **Creator → Reviewer**: 代码提交
- **Reviewer → Launcher**: 质量通过
- **Launcher → Client**: 正式上线

### 质量门控
每个Agent必须达到**专业级**标准才能交接给下一个。

### 并行工作
- Designer可在Discovery进行时开始品牌研究
- Creator可在设计稿部分完成时开始技术架构
- Reviewer全程参与，提前发现问题

## Oskris标准应用

### 必备板块 (7大)
1. **Header** - 导航+Logo
2. **Hero** - 主标题+CTA
3. **Pain Points** - 客户痛点
4. **Services/Solution** - 解决方案
5. **Social Proof** - 案例+见证
6. **About** - 关于我们
7. **CTA + Footer** - 行动引导+联系

### 技术要求
- **响应式**: Mobile-first
- **性能**: Core Web Vitals >90
- **SEO**: Technical SEO + Schema
- **安全**: HTTPS + 基础防护

### 马来西亚本地化
- **语言**: 中文+英文双语
- **货币**: RM定价
- **联系**: WhatsApp优先
- **支付**: TNG/GrabPay考虑
