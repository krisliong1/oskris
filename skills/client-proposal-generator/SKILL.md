# Client Proposal Generator

Generate professional, conversion-optimized proposals for Oskris web design services.

## Instructions

### Step 1: Gather Project Info
Before generating, confirm these details (ask if missing):
- Client business name and industry
- Project type (new site, redesign, e-commerce, landing page)
- Estimated pages/features
- Client budget range (if known)
- Timeline preferences
- Special requirements (multilingual, payment integration, etc.)

### Step 2: Select Package Tier
Match client needs to appropriate tier:

| Tier | Pages | Features | Price Range |
|------|-------|----------|-------------|
| Starter | 1-5 | Static, responsive, basic SEO | RM 1,500 - 3,000 |
| Professional | 5-15 | CMS, forms, SEO, analytics | RM 4,000 - 8,000 |
| Premium | 10-25 | E-commerce, custom features, multilingual | RM 10,000 - 20,000 |
| Enterprise | 25+ | Full custom, API integrations, advanced | RM 25,000+ |

### Step 3: Generate Proposal Document
Create a professional proposal with these sections:

1. **Cover Page** — Oskris branding, client name, date, proposal #
2. **Executive Summary** — 2-3 sentences on what we'll deliver and the value
3. **Understanding Your Needs** — Paraphrase client's requirements showing we listened
4. **Proposed Solution** — Detailed scope of work with deliverables list
5. **Timeline & Milestones** — Gantt-style phases with dates
6. **Investment** — Pricing breakdown (avoid word "cost", use "investment")
7. **Why Oskris** — 3-4 differentiators (AI-powered, fast delivery, Malaysia-focused)
8. **Terms & Conditions** — Payment schedule (50% upfront, 50% on delivery), revision policy
9. **Next Steps** — Clear CTA with contact info and validity period (14 days)

### Step 4: Output Format
Generate as:
- **HTML** (for preview in browser) — default
- **DOCX** (for sending as attachment) — if user requests
- **PDF** (for formal submission) — if user requests

## Proposal Writing Rules

- All prices in RM (Malaysian Ringgit)
- Professional but warm tone — not corporate-stiff
- Emphasize VALUE over features (what client gains, not what we do)
- Include social proof: "We've designed X websites for Malaysian businesses"
- Use client's business name throughout (personalization)
- Timeline should be realistic: minimum 2 weeks for starter, 4-6 weeks for professional
- Always include maintenance/support upsell option
- WhatsApp as primary contact method (Malaysian market standard)

## Brand Details for Proposals
- Company: Oskris Web Design
- Website: oskris.com
- Email: official@oskris.com
- WhatsApp: Include user's number
- Tagline: "Professional Websites for Malaysian Businesses"
