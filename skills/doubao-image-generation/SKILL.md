# Doubao Image Generation Skill

## 简介

豆包（Doubao）是字节跳动开发的AI助手，具备图片生成功能。本文档记录使用豆包生成网站设计图片的最佳实践。

## 适用场景

✅ **适合生成**:
- 网站mockup和界面展示
- 扁平化/插图风格的装饰图
- 图标和小型视觉元素
- 背景图和纹理
- 概念性视觉展示

❌ **不适合**:
- 精确的logo设计（需要矢量工具）
- 真实人物照片（可能有版权/伦理问题）
- 需要精确文字的图片（AI文字生成不可靠）
- 复杂的产品渲染

## 提示词工程

### 核心要素

一个好的图片生成提示词应包含：

1. **主题/内容** - 要画什么
2. **风格** - 什么样的艺术风格
3. **尺寸** - 期望的分辨率
4. **配色** - 主要颜色方案
5. **用途说明** - 帮助AI理解上下文

### 模板公式

```
生成一个 [风格] 的 [内容]，
主题：[具体描述]，
颜色：[配色方案]，
尺寸：[宽x高]，
风格：[艺术风格关键词]
```

## 尺寸建议

### 网站常用尺寸

| 用途 | 推荐尺寸 | 格式 | 说明 |
|------|---------|------|------|
| Hero背景 | 1920x1080 或 1920x800 | JPG | 全屏展示，16:9或更宽 |
| Portfolio案例 | 1200x800 或 800x600 | JPG | 3:2比例 |
| 服务卡片配图 | 800x600 或 600x400 | JPG/PNG | 4:3或3:2 |
| 图标 | 256x256 或 512x512 | PNG | 正方形，透明背景 |
| Logo元素 | 512x512 | PNG | 正方形，透明背景 |
| 装饰性背景 | 1920x1080 | JPG | 可重复使用的纹理 |
| 移动端专用 | 750x1334 | JPG | 竖向，手机屏幕 |

### 响应式建议

生成2-3个版本：
- **Desktop**: 1920x1080
- **Tablet**: 1024x768
- **Mobile**: 750x1334 (竖向) 或 800x600 (横向)

## 质量评估标准

### 技术质量 (1-10分)

1. **清晰度** (Weight: 30%)
   - 9-10分: 完全清晰，放大无模糊
   - 7-8分: 整体清晰，细节略有损失
   - 5-6分: 可接受，但有明显模糊
   - <5分: 模糊不可用

2. **配色准确性** (Weight: 25%)
   - 9-10分: 完美匹配要求的配色
   - 7-8分: 基本符合，略有偏差
   - 5-6分: 颜色方向对，但饱和度/色调不准
   - <5分: 完全偏离

3. **构图合理性** (Weight: 20%)
   - 9-10分: 黄金比例，视觉平衡
   - 7-8分: 构图合理，略有改进空间
   - 5-6分: 勉强可用，需要裁剪调整
   - <5分: 构图混乱

4. **细节准确性** (Weight: 15%)
   - 9-10分: 所有元素都符合要求
   - 7-8分: 主要元素准确，次要有偏差
   - 5-6分: 部分元素错误或缺失
   - <5分: 大量错误

5. **风格一致性** (Weight: 10%)
   - 9-10分: 风格高度统一
   - 7-8分: 整体统一，局部有差异
   - 5-6分: 风格略有冲突
   - <5分: 风格混乱

### 业务适用性评估

✅ **可直接使用** (8-10分)
- 无需修改即可上线
- 完美符合品牌调性
- 视觉吸引力强

⚠️ **需要调整** (5-7分)
- 需要Photoshop微调（裁剪、调色等）
- 整体方向正确，细节需优化
- 可以使用，但不完美

❌ **不可用** (<5分)
- 重大错误或偏差
- 需要重新生成

## 后期优化流程

### 工具链

1. **格式转换**
   ```bash
   # JPG转WebP（减少文件大小）
   cwebp -q 85 input.jpg -o output.webp
   
   # PNG优化
   pngquant --quality=65-80 input.png -o output.png
   ```

2. **尺寸调整**
   ```bash
   # ImageMagick
   convert input.jpg -resize 1920x1080 output.jpg
   
   # 保持比例缩放
   convert input.jpg -resize 1920x1080^ -gravity center -extent 1920x1080 output.jpg
   ```

3. **背景移除**（如果豆包未生成透明背景）
   - 工具: remove.bg
   - Photoshop: 选择并遮住
   - GIMP (免费): 前景选择工具

4. **色彩调整**
   ```bash
   # 调整亮度/对比度
   convert input.jpg -brightness-contrast 10x15 output.jpg
   
   # 色彩校正
   convert input.jpg -level 5%,95% output.jpg
   ```

## 常见问题与解决

### Q1: 生成的图标没有透明背景

**解决方案**:
1. 在提示词中明确写"透明背景"
2. 如果仍无效，使用remove.bg或Photoshop去背
3. 要求PNG格式（JPG不支持透明）

### Q2: 颜色与要求不符

**解决方案**:
1. 使用HEX色值: "配色：#2563eb蓝色+#ffffff白色"
2. 提供色板参考
3. 后期用Photoshop调整色相/饱和度

### Q3: 尺寸比例不对

**解决方案**:
1. 明确宽高比: "16:9横向布局"
2. 生成后用ImageMagick裁剪到精确尺寸
3. 使用Photoshop内容感知填充补足边缘

### Q4: 文字模糊或错误

**解决方案**:
1. **避免生成带文字的图片**（AI文字生成不可靠）
2. 如需文字，后期用CSS overlay添加
3. 或用Photoshop/Figma手动添加文字

### Q5: 风格不统一（多次生成）

**解决方案**:
1. 保存第一次生成的提示词，后续严格复用
2. 添加"与之前图片相同风格"
3. 使用相同的配色方案和风格关键词
4. 批量生成后人工筛选一致的

## 最佳实践总结

### DO ✅

1. **明确具体** - 提示词越详细越好
2. **测试迭代** - 生成多个版本，选最佳
3. **批量生成** - 一次性生成多个相同风格的图
4. **保存提示词** - 记录成功的提示词供复用
5. **后期优化** - 不期望AI生成完美图片，准备后期调整
6. **版权意识** - 了解使用条款，商业使用需确认
7. **A/B测试** - 在网站上测试不同图片的转化率

### DON'T ❌

1. ❌ 依赖AI生成文字（不可靠）
2. ❌ 生成真实人物肖像（伦理/法律风险）
3. ❌ 期望一次完美（需要多次迭代）
4. ❌ 忽视品牌一致性（要统一风格）
5. ❌ 直接使用未优化图片（需压缩/格式转换）
6. ❌ 忽视响应式（要准备多尺寸）
7. ❌ 忘记备份原图（保留高分辨率原图）

## 工作流程建议

### 标准流程

```
1. 需求分析
   └─ 确定需要什么图片、用途、尺寸、风格

2. 提示词设计
   └─ 根据模板编写详细提示词

3. 批量生成
   └─ 一次生成3-5个变体

4. 筛选评估
   └─ 用评分标准选出最佳

5. 后期优化
   └─ 调整尺寸、格式、颜色

6. 集成测试
   └─ 放入网站测试效果

7. 性能优化
   └─ 压缩、WebP转换、CDN部署

8. 效果追踪
   └─ 监控转化率、跳出率等指标
```

### 时间规划

- 需求分析: 10分钟
- 提示词设计: 5分钟/图
- 批量生成: 5-10分钟
- 筛选: 5分钟
- 后期优化: 10-15分钟/图
- 集成测试: 10分钟

**总计**: 单个图片约30-40分钟，批量项目1-2小时
