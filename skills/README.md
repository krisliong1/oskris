# Skills 分类目录

## 📁 目录结构

### core/ 核心系统
- **work-rules**: 核心工作规则（关键词系统、优先级）
- **core-work-rules**: 核心工作规则（扩展版）
- **secrets-manager**: 密钥和配置管理
- **conversation-startup**: 新对话自动启动
- **conversation-starter**: 对话启动器
- **auto-storage**: 自动存储到 GitHub/VPS
- **claude-md**: CLAUDE.md 管理

### web-development/ 网站开发
- **project-workflow**: 完整项目工作流
- **requirements-analyst**: 需求分析
- **design-consultant**: 设计方案
- **frontend-builder**: 前端开发实现
- **frontend-design**: 前端设计规范

### content/ 内容和翻译
- **auto-translate**: 自动翻译（英文→中文）
- **smart-info-manager**: 智能信息管理

### product/ 产品相关
- **product-self-knowledge**: 产品自我认知
- **app-recommendations**: App 推荐

## 📋 使用说明

每个 Skill 包含：
- `SKILL.md`: 完整的 Skill 定义
- 触发条件、执行流程、示例

## 🔄 更新流程

1. 本地修改 `/mnt/skills/user/` 中的 Skill
2. 运行自动存储流程
3. GitHub 自动同步
