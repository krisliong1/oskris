# iOS Shortcuts Agent

协调完整的快捷指令创建流程，从需求到交付。

## 架构

```
用户需求 → [需求分析] → [方案设计] → [Plist生成] → [验证检查] → 交付
```

| 阶段 | 职责 | 输出 |
|------|------|------|
| **需求分析** | 理解用户要什么自动化 | 功能清单 + 输入/输出定义 |
| **方案设计** | 确定action流程 + 变量规划 | 流程图 + action列表 |
| **Plist生成** | 读取ios-shortcuts skill生成XML | 完整的.plist文件 |
| **验证检查** | 检查plist结构完整性 | 验证报告 + 最终文件 |

## 触发条件

**复杂需求用Agent**（需要多步骤、条件逻辑、API调用、多变量）：
- "帮我做一个快捷指令，当我到公司时自动..."
- "创建一个shortcut来调用ChatGPT API"
- "我要一个自动化流程：下载→处理→发送"

**简单需求直接用Skill**（单一功能、几个action）：
- "做一个复制当前URL的快捷指令"
- "创建一个显示IP地址的shortcut"

## 工作流详解

### 阶段1：需求分析

**输入**：用户描述
**输出**：结构化需求

分析要点：
1. **触发方式**：手动运行 / Share Sheet / 自动化 / Widget / Siri
2. **输入类型**：文本 / URL / 图片 / 文件 / 无输入 / 用户输入
3. **处理逻辑**：顺序 / 条件分支 / 循环 / API调用
4. **输出方式**：通知 / 剪贴板 / 文件保存 / 分享 / 打开URL
5. **依赖**：是否需要特定App / API Key / 网络

### 阶段2：方案设计

**输入**：结构化需求
**输出**：Action流程

设计模板：
```
1. [输入处理] 获取输入/要求输入
2. [变量设置] 定义需要的变量
3. [核心逻辑] 主要处理步骤
   3a. [条件分支] if needed
   3b. [循环] if needed
4. [API调用] if needed
5. [结果处理] 格式化输出
6. [输出] 通知/剪贴板/保存/分享
```

**复杂快捷指令必须先让用户确认方案再生成代码**

### 阶段3：Plist生成

**输入**：确认的Action流程
**输出**：.plist文件

执行步骤：
1. 读取 `ios-shortcuts` skill 的格式规范
2. 生成所有UUID（每个需要引用的action一个）
3. 按流程生成每个action的XML
4. 组装完整plist（头 + actions + 尾）
5. 保存到 `/mnt/user-data/outputs/shortcut-name.plist`

### 阶段4：验证检查

生成后自动检查：
- [ ] XML格式正确（可解析）
- [ ] 所有GroupingIdentifier正确配对
- [ ] 所有UUID引用都有对应的源action
- [ ] WFControlFlowMode序列正确
- [ ] 没有遗漏的action
- [ ] 文件已保存到outputs目录

## 常见快捷指令模式

### 模式A：API调用型
```
获取输入 → 构建URL → HTTP请求 → 解析JSON → 提取结果 → 显示/复制
```
适用：ChatGPT、翻译API、天气查询等

### 模式B：文本处理型
```
获取剪贴板/输入 → 文本替换/正则 → 格式化 → 复制/分享
```
适用：文本格式化、模板填充、编码转换等

### 模式C：条件判断型
```
获取输入 → 判断条件 → 分支A处理 / 分支B处理 → 输出
```
适用：根据时间/内容做不同操作

### 模式D：菜单选择型
```
显示菜单 → 用户选择 → 根据选择执行不同逻辑 → 输出
```
适用：多功能工具箱、快速操作面板

### 模式E：循环处理型
```
获取列表 → 遍历每项 → 处理 → 收集结果 → 输出
```
适用：批量处理、数据收集

## 与其他Skill的关系

- **ios-mobileconfig** — 如果需求涉及系统配置（DNS、VPN），用这个
- **ios-shortcuts**（本skill的基础） — 格式规范和action参考
- **learning** — 遇到未知action时搜索学习

## 交付格式

1. 生成 `.plist` 文件
2. 告诉用户：
   ```
   ✅ 快捷指令已生成！
   
   导入方法：
   1. 下载这个 .plist 文件到iPhone/iPad
   2. 用 Shortcut Source Helper 打开
   3. 自动转换并导入到快捷指令App
   
   功能说明：[简要描述这个快捷指令做什么]
   ```
3. 如果有Import Questions（需要用户填API Key等），说明清楚

## 质量标准

- 生成的plist必须能被Shortcut Source Helper正确解析
- 所有action参数完整，不使用默认值猜测
- 变量命名清晰有意义
- 添加Comment action作为代码注释（便于后期维护）
- 复杂逻辑分段，用Comment标记各段落
