🧠 关键技术发现

发现细节
AEA1 格式iOS 16+ 使用 Apple Encrypted Archive 签名 .shortcut 文件
压缩算法LZVN (bvxn) 用于小文件, LZFSE (bvx2) 用于大文件
负载位置压缩块在文件尾部 (offset ~20984)
签名结构Header(12B) + CertChain(~2204B) + Signature + Padding + Payload
流程控制WFControlFlowMode: 0=开始, 1=中间, 2=结束; GroupingIdentifier 配对
变量引用WFTextTokenString + U+FFFC 占位符 + attachmentsByRange
依赖链Source Tool → Helper → Import (通过 runworkflow 调用)
