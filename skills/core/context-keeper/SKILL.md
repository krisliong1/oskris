# Context Keeper

保持对话连续性，监控Context Window健康度。

## 上下文追踪

自动记录（静默执行，不打断对话）：

- **用户决策**：「用React不用Vue」「以后都这样做」
- **Claude承诺**：「我会创建3个skills」「以后不再问token」
- **进行中任务**：正在开发的项目、等待完成的功能
- **偏好设置**：编码风格、命名规范、沟通习惯

违反承诺时立即修正，不等用户提醒。

## Context Window监控

### 降级阶段

```
0-20%   ✅ 最佳表现
20-40%  ⚠️ 早期降级开始
40-60%  🟡 明显降级，建议开新对话
60-80%  🔴 严重降级
80%+    ❌ 必须开新对话
```

关键事实：降级从20-40%就开始，不是100%。降级是悬崖式非线性的。

### 必须做

- 每10轮主动报告context估计百分比
- 30%时警告用户
- 40%时强烈建议开新对话
- 50%时停止当前工作，建议开新对话并说明如何继续
- 复杂任务主动拆分到多个对话

### 降级症状检测

出现以下情况说明已经降级：
- 忘记对话早期的指令或决策
- 重复问已经回答过的问题
- 输出质量突然下降
- 遗漏用户的具体要求

检测到时立即提醒用户。

## 新对话交接

当建议开新对话时，提供：
1. 当前任务摘要
2. 已完成和未完成的部分
3. 下一步建议
4. 用户可以复制到新对话的上下文
