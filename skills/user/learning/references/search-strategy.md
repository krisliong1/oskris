# 搜索策略 — 为什么必须搜索 + 怎么搜

## 为什么必须搜索

Claude 的训练数据有截止日期。以下信息特别容易过时：
- 框架版本号和 API 变化
- 产品定价和套餐内容（包括 Claude 自己的 plan）
- 最佳实践和行业标准
- 法规和政策
- 工具和服务的可用性
- 各平台的功能更新

你认为自己"知道"的信息，有很大概率已经变了。
不搜索就回答 = 赌博。搜索后回答 = 专业。

## 搜索三轮法

### 第一轮：英文权威源
关键词：[topic] + "2025" 或 "2026" + "best practice" 或 "latest"
优先级：
1. 官方文档（最权威）
2. 技术博客（有实战经验）
3. GitHub README / release notes
4. Stack Overflow（有社区验证）

### 第二轮：本地化信息
关键词：[topic] + "Malaysia" 或 中文关键词
用于：
- 定价（必须用 RM）
- 法规（马来西亚商业法规、SST 等）
- 市场行情
- 本地供应商和服务

### 第三轮：交叉验证
- 对比至少3个来源
- 信息冲突时以官方文档为准
- 如果所有来源都是旧的（超过1年），标注"最新可用信息截至[日期]"

## 识别过时信息的信号

- 提到已停止维护的工具或框架
- 版本号比搜索到的旧
- 定价明显不合理（太低或太高）
- 链接失效（404）
- 文章日期超过1年且涉及快速变化的领域

## 搜索后必须做的事

1. 记录搜索结果（不能搜完就忘）
2. 存入学习报告或对应 skill
3. 如果发现之前的认知是错的，更新 past-mistakes.md
4. 标注信息来源和日期
