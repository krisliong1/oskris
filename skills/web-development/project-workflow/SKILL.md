# Project Workflow — 网站项目全流程

协调所有skill，管理项目从获客到交付的完整流程。

## Project Lifecycle

```
1. Lead Generation → 2. Consultation (requirements-analyst)
→ 3. Proposal & Contract → 4. Design (design-consultant)
→ 5. Development (frontend-builder) → 6. Testing & Review
→ 7. Launch → 8. Training & Handover → 9. Post-Launch Support
```

## Phase 1: Lead Generation

**渠道**: 本地拜访、商业活动、客户推荐、Kong Kiong合作伙伴、oskris.com作品集、Facebook/Instagram/Google Ads

**客户筛选（红线）**:
- 预算低于RM1,500 → 婉拒
- 要求一周内完成 → 不现实
- 拒绝付定金 → 风险太高
- 持续改需求 → 需明确scope

## Phase 2: Initial Consultation

触发 `requirements-analyst` skill:
1. 了解业务背景和目标
2. 定义网站功能需求
3. 确定目标受众
4. 竞争对手分析
5. 确定预算和时间线
6. 输出: requirements.md

## Phase 3: Proposal & Contract

### Proposal Structure
```
1. Executive Summary — 理解客户需求的总结
2. Proposed Solution — 推荐方案和套餐
3. Sitemap — 页面结构
4. Timeline — 分阶段时间表
5. Investment — 价格和付款条件
6. Why Oskris — 优势和案例
7. Terms — 修改次数、版权、维护
```

### 付款条件
- 50% 定金开工
- 30% 设计稿确认后
- 20% 上线后7天内

### Contract 要点
- Scope of work 明确列出
- 修改次数上限（通常3次大改）
- 额外功能按时收费
- 所有内容由客户提供，延迟不归Oskris
- 项目暂停超30天需重新报价

## Phase 4: Design Phase

触发 `design-consultant` skill:
1. 品牌分析 → 配色/字体/风格
2. Wireframe → 页面线框图
3. 高保真设计稿
4. **客户确认** ← 关键节点
5. 输出: design-spec.md, brand-kit.md

## Phase 5: Development Phase

触发 `frontend-builder` skill:
1. 搭建开发环境
2. 按设计稿coding
3. 响应式适配
4. 功能开发
5. 内部测试
6. 输出: working website

## Phase 6: Testing & Review
- Cross-browser testing (Chrome, Safari, Firefox)
- Mobile responsive (3+ breakpoints)
- Forms and CTAs working
- Page speed <3s
- SEO audit (Lighthouse ≥90)
- Accessibility check
- Client preview and feedback

## Phase 7: Launch & Deployment
1. 最终客户确认
2. 域名/DNS配置
3. SSL证书安装
4. 部署上线
5. 功能验证
6. Google Analytics + Search Console
7. 提交sitemap

## Phase 8: Training & Handover
交付物:
- Admin credentials
- Content update guide
- Image specifications
- Backup procedures
- Support contact info

## Phase 9: Post-Launch Support
- 30天免费bug修复
- 月度维护套餐（可选 RM200-500/月）
- 内容更新、安全更新、性能监控
- 24小时内响应紧急问题

- 支出: 域名、主机、工具订阅、广告
- 税务: SST threshold RM500,000/年

## Client Communication

**响应时间**: WhatsApp 2小时内 | Email 24小时内 | 紧急电话即时
**更新频率**: 每周一次进度报告 | 关键节点即时通知

### 沟通模板

**项目启动**:
> Hi [Name]，感谢选择Oskris！项目已启动，预计[日期]完成。如有任何问题随时WhatsApp我。

**设计稿确认**:
> [Name] 你好，设计稿已完成，请查看链接: [URL]。有任何修改意见请在3天内反馈。

**上线通知**:
> 恭喜！[Website]已正式上线 🎉 接下来30天我们提供免费技术支持。

## Handling Difficult Situations

**客户要求大改已确认的设计**: 说明scope change，提供额外报价，记录邮件确认

**客户拖延提供内容**: 设定deadline，延迟影响上线日期，用placeholder先开发

**客户要求免费加功能**: 礼貌说明scope，提供额外功能报价，记录所有变更

**客户不满意设计**: 了解具体不满点，提供2-3个替代方案，参考竞对做调整

## Success Metrics
- 客户满意度 ≥4.5/5
- 项目按时交付率 ≥80%
- 回头客率 ≥30%
- 每月新客 ≥3个
- 平均项目利润 ≥60%

## Scaling Strategy
**1-10个项目**: 自己做全部
**10-30个项目**: 外包开发，自己管设计+客户
**30+项目**: 建团队，标准化流程

## Integration
- requirements-analyst → Phase 2 需求分析
- design-consultant → Phase 4 设计
- frontend-builder → Phase 5 开发
- web-design-studio → 协调所有agent
