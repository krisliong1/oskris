# 常驻AI学习审核系统

## 核心原则
**常驻AI = 学徒，会犯错**  
**主AI = 师傅，必须审核**

## 审核流程

### 1. 任务完成后
```
常驻AI完成任务
    ↓
生成学习报告（draft-learning.md）
    ↓
提交给主AI审核
    ↓
主AI验证正确性
    ↓
批准 → 更新MEMORY.md
拒绝 → 纠正 + 重新提交
```

### 2. 学习报告格式
```markdown
# 学习报告草稿

## 任务信息
- 任务: 备份Claude Desktop 10GB
- 时间: 2026-02-21 09:22
- 结果: 成功

## 我学到的
1. **rsync参数优化**
   - 使用 -avz --progress
   - 速度：6MB/s
   - 我认为：这是最优参数

2. **排除文件**
   - 排除 node_modules
   - 省30%时间
   - 我认为：应该总是排除

## 提出的最佳实践
1. 备份前检查磁盘空间
2. 使用md5验证完整性
3. 排除缓存文件夹

## 待审核问题
- 是否应该总是排除.git？
- 压缩级别6是最优吗？
- VPS路径规范是什么？

## 请求批准
将以上经验写入MEMORY.md？
```

### 3. 主AI审核清单

#### ✅ 检查技术正确性
- [ ] 命令参数是否正确？
- [ ] 有没有安全风险？
- [ ] 会不会误删数据？
- [ ] 性能优化合理吗？

#### ✅ 检查逻辑推理
- [ ] 因果关系正确吗？
- [ ] 是否过度泛化？（"总是"、"永远"要警惕）
- [ ] 有没有遗漏边界情况？

#### ✅ 检查用户偏好
- [ ] 符合用户习惯吗？
- [ ] 违反用户规则吗？（如"不删文件"）
- [ ] 优先级对吗？

#### ✅ 检查完整性
- [ ] 是否记录了失败原因？
- [ ] 有没有遗漏重要步骤？
- [ ] 能否复现？

### 4. 审核结果

#### 批准 ✅
```markdown
## 主AI审核意见

**批准**: ✅

**修正建议**:
1. "总是排除.git" → 改为"备份时排除，归档时保留"
2. 补充失败重试机制

**批准写入MEMORY.md**，但需修正上述2点。
```

#### 拒绝 ❌
```markdown
## 主AI审核意见

**拒绝**: ❌

**严重错误**:
1. 你学到"删除.git省空间" - **错误！**
   - .git是版本控制核心，不能删
   - 应该用.gitignore排除大文件

2. 你认为"rsync -avz --delete安全" - **危险！**
   - --delete会删除目标多余文件
   - 备份场景禁止使用

**要求**:
1. 重新学习rsync文档
2. 修正MEMORY.md中的错误认知
3. 重新提交审核
```

## 审核频率

### 新手期 (Level 1)
- **每次任务后都审核**
- 严格检查
- 及时纠正

### 熟练期 (Level 2)
- **关键任务必审**
- 常规任务抽查
- 定期review MEMORY.md

### 专家期 (Level 3+)
- **高风险操作审核**
- 季度review
- 信任但验证

## 常见错误模式

### 1. 过度优化
```
❌ 常驻AI: "删除所有日志文件可以省空间"
✅ 主AI纠正: "保留最近7天日志，用于troubleshooting"
```

### 2. 误判成功
```
❌ 常驻AI: "rsync退出码0 = 成功"
✅ 主AI纠正: "还需验证文件数量和md5"
```

### 3. 忽略边界情况
```
❌ 常驻AI: "备份命令：rsync -avz source/ target/"
✅ 主AI纠正: "需要先检查：目标磁盘空间、网络连通性、权限"
```

### 4. 形成坏习惯
```
❌ 常驻AI: "失败就重试3次"
✅ 主AI纠正: "先分析失败原因，再决定是否重试"
```

## 纠正机制

### 立即纠正
```
发现错误 → 主AI立即介入 → 停止常驻AI → 纠正MEMORY.md
```

### 教学纠正
```
常驻AI提问 → 主AI解答 → 记录到MEMORY.md
```

### 实战纠正
```
让常驻AI重做 → 观察是否改正 → 验证学习效果
```

## 主AI的职责

### 1. 守门人
- 批准/拒绝学习内容
- 防止错误知识积累
- 保护系统安全

### 2. 教师
- 解答常驻AI疑问
- 提供正确方法
- 分享最佳实践

### 3. 质检员
- 定期review MEMORY.md
- 发现隐藏错误
- 淘汰过时知识

### 4. 协调者
- 跨AI知识共享
- 避免重复学习
- 统一标准

## 成功指标

### 短期
- 审核通过率 > 80%
- 严重错误 = 0

## 注意事项

### 不要过度严格
- 允许小错误（学习过程）
- 鼓励实验
- 批准有价值的尝试

### 不要完全信任
- 即使Level 4大师也会犯错
- 关键操作必须审核
- 定期review历史决策

### 保持平衡
- 严格但不扼杀创新
- 信任但保持警惕
- 教导而非命令
