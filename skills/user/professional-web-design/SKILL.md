# Professional Web Design Skill

## Trigger
Use this skill for ANY website design project or when user mentions web design work. Always read this before starting any client project.

## Core Principles (从实习生到专业)

### 🚫 NEVER (实习生做法)
- 直接写代码不规划
- 跳过客户发现阶段
- 没有设计稿就开发
- 不知道市场定价

### ✅ ALWAYS (专业做法)
- 先 Plan 后 Execute
- 完整 7 阶段流程
- 遵循 2026 技术标准
- 基于市场行情定价

---

## 完整工作流程 (7 阶段)

### 阶段 1: 客户发现 (1-2 天)
**必须输出**:
- [ ] 客户问卷调查
- [ ] 业务目标文档
- [ ] 目标受众分析
- [ ] 项目范围定义 (Scope Document)

**关键问题**:
1. 业务类型和目标？
2. 目标受众是谁？
3. 竞争对手有哪些？
4. 预算范围？
5. 时间要求？

### 阶段 2: 战略规划 (2-3 天)
**必须输出**:
- [ ] 网站地图 (Sitemap)
- [ ] 用户旅程图 (User Journey Map)
- [ ] 内容策略
- [ ] SEO 关键词策略

### 阶段 3: 设计方案 (3-5 天)
**必须输出**:
- [ ] 线框图 (Wireframes)
- [ ] 视觉设计稿 (Mockups)
- [ ] 品牌指南 (色彩/字体/图标)
- [ ] 设计提案演示

**包含**:
- 色彩方案 (Color Palette)
- 字体系统 (Typography)
- 图标风格 (Iconography)
- 交互动画 (Micro-animations)

### 阶段 4: 开发实现 (7-14 天)
**技术栈 (2026 标准)**:
- Meta-框架: Next.js 15 / Nuxt
- 样式: Tailwind CSS
- CMS: WordPress / Webflow / Headless CMS
- AI 集成: GitHub Copilot
- 性能: Core Web Vitals 3.0

**必须输出**:
- [ ] 响应式网站 (Mobile-first)
- [ ] 性能优化报告 (PageSpeed Insights)
- [ ] 浏览器兼容性测试
- [ ] 安全性检查 (SSL, WCAG 3.0)

### 阶段 5: 内容填充 (3-5 天)
**包含**:
- [ ] SEO 优化文案
- [ ] 专业图片/视频
- [ ] CTA 按钮优化
- [ ] 元标签设置

### 阶段 6: 测试上线 (2-3 天)
**检查清单**:
- [ ] 移动端测试 (iOS/Android)
- [ ] 桌面端测试 (Chrome/Safari/Firefox)
- [ ] 加载速度 <3秒
- [ ] SEO 检查 (Google Search Console)
- [ ] 表单功能测试
- [ ] Google Analytics 4 集成

### 阶段 7: 交付培训
**包含**:
- [ ] 网站管理培训 (CMS 使用)
- [ ] 完整文档交付
- [ ] 维护计划说明
- [ ] 30天支持期

## 马来西亚定价策略 (2026)

### 基础套餐 (RM 1,500-3,000)
- 5-7 页面
- 模板定制
- 基础响应式
- 联系表单
- **适合**: 初创企业

### 专业套餐 (RM 4,000-8,000)
- 10-15 页面
- 定制设计
- SEO 基础设置
- 内容策略
- 6 个月维护
- **适合**: 中小企业

### 高级套餐 (RM 10,000-20,000)
- 无限页面
- 完全定制设计
- 高级 SEO 策略
- 电商功能
- AI 个性化
- 12 个月维护
- **适合**: 成熟企业

### 企业级 (RM 25,000+)
- 多语言支持
- 复杂功能开发
- API 集成
- 会员系统
- **适合**: 大型企业

### 额外费用
**域名**: RM 60-120/年
**托管**: RM 300-1,500/年
**维护**: RM 300-800/月
**SEO**: RM 1,000-10,000/月

## 性能标准 (Core Web Vitals 3.0)

- LCP (最大内容绘制) < 2.5s
- FID (首次输入延迟) < 100ms
- CLS (累积布局偏移) < 0.1

## 专业 vs 实习生对比

| 维度 | 实习生级别 | 专业级别 |
|------|-----------|---------|
| 开始方式 | 直接写代码 | 先调研、规划、再执行 |
| 客户沟通 | 模糊理解 | 结构化问卷、明确需求 |
| 设计流程 | 跳过设计稿 | 线框图 → 视觉稿 → 确认 |
| 代码质量 | 能用就行 | 最佳实践、性能优化 |
| 测试 | 自己看看 | 多设备、多浏览器测试 |
| 交付 | 给文件 | 完整文档 + 培训 + 支持 |
| 定价 | 不知道 | 基于市场行情和价值 |
